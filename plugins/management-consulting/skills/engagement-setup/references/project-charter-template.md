# Project Charter Template

Complete this together during the kickoff. It is the contract between everyone on what you are doing and how. Fill each field with a real sentence. A charter of empty cells is a to-do list, not an agreement.

```
Project Charter: [Project Name]

1. PROJECT OVERVIEW

Background:
[Why this project exists now, in one or two sentences]

[The problem you are solving, stated so the sponsor would agree word for word]
```
