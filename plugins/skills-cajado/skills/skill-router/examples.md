# Sample rows

Real contests from one setup. Copy a row only if the user has the skills it
names, and check the reasons against the skills' current content.

## Instagram

| Task | Use | Don't use | After |
|---|---|---|---|
| Reel script, video hook | `ig-reel` | `hook-writer-sms`: doesn't score the hook or read the voice file | `ig-human` |
| Post or reel caption | `ig-caption` | `caption-writer-sms`: doesn't check the 125-character cut, suggests too many hashtags | `ig-human` |
| Carousel | `ig-carousel` | `carousel-writer-sms`: text only, no 1080×1350 files | `ig-human` |
| Copy for TikTok, LinkedIn, YouTube or Pinterest | `caption-writer-sms` | `ig-*`: Instagram only | |
| Remove the AI feel from Instagram copy | `ig-human` | `slopmonster`: doesn't know caption tics | |

## Interface and design

| Task | Use | Don't use | After |
|---|---|---|---|
| New screen, page or component | `frontend-design` | `ui-ux-pro-max`: generic catalog; consult it only for a palette, font pairing or chart type | `better-interface` |
| Review or polish an existing UI | `better-interface` | `design:design-critique`: generic, no exact values | |
| In-app copy (buttons, errors, empty states) | `better-writing` | `brand-copywriter`: that's sales copy | |
| Build an animation | `emil-design-eng` | | `/review-animations` |
| Logo | `svg-logo-designer` | `canvas-design`: for posters and art | |
